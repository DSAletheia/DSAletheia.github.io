Datenschutzerklärung

Stand: 11.10.2026

Welche Daten verarbeitet werden

rclone-steammachine greift mit Zustimmung des Kontoinhabers über die Google-Drive-API auf dessen eigenes Google Drive zu. Es lädt dort ausschließlich Dateien hoch und verwaltet sie, die der Kontoinhaber selbst auf seinem Rechner erzeugt hat (Trainingsprotokolle).

Speicherung und Weitergabe

  • Das Zugriffstoken wird nur lokal auf dem Rechner des Kontoinhabers gespeichert.
  • Es werden keine Daten an den Entwickler, an Dritte oder an andere Server als die von Google übertragen.
  • Es gibt kein Tracking, keine Werbung und keine Analyse.
  • Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
